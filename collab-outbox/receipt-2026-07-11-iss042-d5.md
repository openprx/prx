# ISS-042 D5 Injection Overbudget Diagnostic Receipt

## Scope

- Branch/base: `fix/iss042-d5-injection-overbudget-diagnostic` off `974452b4`.
- Implemented only D5: Redux provider preflight emits a user-visible diagnostic when injected `@path`/memory context makes the provider history exceed the hard context limit while the original persisted history still fits.
- No commit made.

## Code Changes

- `src/chat/dispatcher.rs:1767-1819`
  - Added `format_injection_overbudget_diagnostic`, `redux_injection_overbudget_diagnostic_text`, and `send_redux_injection_overbudget_diagnostic`.
  - Detection compares `plan_context_budget(enriched_history)` vs `plan_context_budget(original_history)`.
  - Emits only when enriched is over hard limit and original is not over hard limit.
  - Diagnostic contains only an approximate token delta; it never includes injected text.
  - Uses a separate `last_injection_overbudget_feedback` dedupe slot, matching the existing compaction feedback pattern without merging the two feedback streams.
- `src/chat/dispatcher.rs:1902,1936,1979-1989`
  - Hooked the diagnostic into the existing Redux preflight hard-limit branch next to trim/compaction feedback.
  - Trim/compaction behavior is unchanged; this only sends an additional `Action::SystemMessageAdded`.
- `src/chat/action.rs:315-332`, `src/chat/state.rs:1045-1065`, `src/chat/state.rs:1640-1724`
  - Added optional `Action::StartLLMTurn.compaction_guard_history`.
  - Reducer forwards it into `Effect::StartTurn`, falling back to the existing `self.session.history.clone()` behavior for tests/non-chat callers.
- `src/chat/mod.rs:6891-6897`
  - Live Redux chat now passes `persisted_history_for_turn.clone()` as the guard/original history source.
  - This fixes the real TUI path so D5 can distinguish original prompt from provider-only enrichment.
